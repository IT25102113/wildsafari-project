Payment & Invoice Processing
Patabendi M.K.K · IT25101973 · Finance Officer
Module 6
CREATE
Process Payment / Generate Invoice
Customer pays via Card or Bank Transfer (slip upload). System auto-generates 10% VAT Tax Invoice upon approval using Factory Pattern.
READ
Finance Dashboard / View Invoice / Revenue Report
View total revenue, pending bank transfers, all payment transactions, generated tax invoices list.
UPDATE
Approve / Reject Bank Transfer / Process Refund / Void Invoice
Finance officer verifies uploaded bank slips (Approve = PAID / Reject). Refund processed for cancelled bookings. Invoice can be VOID'd.
DELETE
Delete Tax Invoice / Delete Payment Transaction
Permanently delete erroneous invoices. Delete payment transactions (linked invoices auto-removed to maintain DB integrity).
Related Database Tables
🗄 payments 🗄 invoices
