Guide: How to Inspect & Manage Database Tables
Method 1: Built-in Live Web Explorer (Easiest • No extra software)

You are already on this screen! Simply click any table on the left sidebar to inspect live data, filter columns, and check row counts.

Method 2: Directly inside IntelliJ IDEA (Ultimate or Community)
  1. In IntelliJ IDEA, look at the far right sidebar and click the "Database" tool icon.
  2. Click the + button → Data Source → MySQL.
  3. Enter your credentials:
    • Host: localhost (Port: 3306)
    • User: root
    • Password: root123
    • Database: safari_db
  4. Click "Test Connection" (if prompted to download driver, click Download Driver).
  5. Click OK. You can now double-click any table to edit, insert, or view records like an Excel sheet!
Method 3: Using XAMPP phpMyAdmin (Web Browser)
  1. Open XAMPP Control Panel and click Start next to MySQL.
  2. Open your web browser and go to: http://localhost/phpmyadmin
  3. In the left sidebar, click on safari_db.
  4. Click on any table (e.g. bookings, safari_packages) to browse, export to CSV/PDF, or run custom SQL queries.
